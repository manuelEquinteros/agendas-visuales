# Agendas Visuales

Proyecto desarrollado para el Seminario Final de la carrera de Informática.

La aplicación permite crear, editar y administrar agendas visuales para personas con autismo. Incluye asistencia mediante inteligencia artificial para interpretar instrucciones en lenguaje natural y utiliza pictogramas de ARASAAC.

## Tecnologías

### Backend

- Java 25 LTS
- Spring Boot 4.1.1
- Spring Framework 7
- Spring AI 2.0.1
- PostgreSQL 18
- Flyway
- Maven

### Frontend

- Angular 22
- TypeScript 6
- Node.js 24 LTS

### Servicios externos

- Google Gemini Developer API
- ARASAAC REST API
